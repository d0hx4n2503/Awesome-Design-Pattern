# GitHub Assets

Thư mục này dành cho tài liệu hỗ trợ vận hành repo trên GitHub.

## Nội Dung Dự Kiến

- Hướng dẫn đặt issue/PR.
- Quy ước milestone khi bắt đầu implement code.
- Checklist release tài liệu hoặc ví dụ code trong tương lai.

Hiện tại repo đang ở giai đoạn documentation-first, nên chưa cần automation phức tạp.
